# Question 20

**Question:** Complete workflow: create, edit, search, replace, copy, paste, save and exit a text file.

## Commands / Solution

Run `vi lab5.txt`; press `i` and type text; press `Esc`; search with `/word`; replace all using `:%s/old/new/g`; copy a line with `yy` and paste with `p`; finally save and exit using `:wq`. Use words that exist in your file.
