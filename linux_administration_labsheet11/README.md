# Linux Administration Lab Sheet 11 — Archive & Compression

This folder contains 20 separate Bash script files, one for each question in the lab sheet.

## How to run
1. Open a Linux terminal in this folder.
2. Make a script executable, for example:
   `chmod +x 01_create_directory_and_files.sh`
3. Run it:
   `./01_create_directory_and_files.sh`

Run the scripts in numerical order where later questions use files or archives created by earlier questions. Some scripts create their own sample files or directories.

**Note:** These scripts use standard Linux commands (`tar`, `gzip`, `gunzip`, `zip`, and `unzip`). If `zip` or `unzip` is missing, install the package using your distribution's package manager.
