# Linux Administration Lab Sheet 8 — Package Management

**Subject:** Linux Lab  
**Subject Code:** UAC02P  
**Aim:** Practice Linux package management using `rpm` and `dnf`, including repository management and package installation, update, and removal.

## Environment
Red Hat Enterprise Linux (RHEL), Rocky Linux, or AlmaLinux with `rpm` and `dnf`.

## How to use
- Each question has its own file (`Q01_...sh` through `Q20_...sh`).
- Read the comments before running a script.
- Run scripts from a terminal with `bash Q01_...sh`, etc.
- Some commands may require `sudo` and an internet connection.
- Package names and repository availability can differ by distribution.
- Questions that install, update, or remove software are clearly marked. Review the command before running it.
- For practice, use a VM or lab system. Do not remove packages needed by the operating system.
- Replace example package names where appropriate. The examples use common packages such as `tree`, `curl`, and `bash`.

## Files
Each script includes the original question as a comment, followed by example commands.
